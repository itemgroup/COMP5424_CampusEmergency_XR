# Original project content provenance

Created on 2026-10-01 by Codex at the user's direction for this COMP5424 project. The elevator facade, sign plate, English SVG/PNG labels and four WAV cues were generated from simple geometry, text and mathematical tones in `Tools/build_original_assets.py`.

No reference-repository models, recorded voices, sampled sound, logos or safety pictograms were copied into these files. PNG labels use locally installed font rendering; no font file is included. SVG labels remain editable and may render with a different installed sans-serif font.

These are project-authored draft assets supplied for the team to use and edit. They are not official or certified fire-safety signs, a verified elevator model, or an official fire-alarm sound. Keep this provenance with the project and record any subsequent changes. A public repository licence for the team's original work remains the team's decision; the Kenney files separately retain their original CC0 notice.
