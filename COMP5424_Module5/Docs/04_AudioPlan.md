本包交付四个原创 WAV 和三个 Kenney CC0 OGG 备选 UI 音效。旁白只交付英文录音稿，未生成或取得语音录音；不把文字稿称为已完成配音。原创 WAV 用正弦波和渐入渐出合成，没有采样第三方录音。

## 环境音与旁白

环境音不是最小版必需项，当前默认静音，不加入火焰轰鸣、尖叫、脚步循环或紧张背景音乐。这样不会额外遮盖英文说明，也不制造真实危险强度。如果团队以后加入环境音，须另登记来源、许可、循环规则并重新检查旁白可听性。

录音者可逐条读取 `Content/VoiceScripts` 的英文，使用清晰、自然、平静的语气。按键说明在确认绑定后再录音。记录谁录制、日期、文件名和许可；如使用 TTS，需核实该服务的音频使用条款，不复用未知来源的人声或模仿他人声音。音轨完成后按实际音频制作字幕时间，不能提前编造精确同步时间。

## 交给声音与 UI 开发者

- 普通 UI 音默认用 2D、非循环播放；首次头显试听从较低音量开始，再依据参与者/监督者反馈调整。不要把电脑音量当作真机验证结果。
- 同时最多播放一条教学语音；打开下一条、暂停或退出时由 UI/音频逻辑停止或暂停前一条。提示音不得掩盖语音。
- 静音时全部关键指令仍由屏幕和环境标识表达；非语音短音效也必须有对应可见状态变化。
- 不用延迟动画、长音轨或自动播放时长锁住 Continue 按钮。重复选择和恢复后的声音行为由团队实际检查。
