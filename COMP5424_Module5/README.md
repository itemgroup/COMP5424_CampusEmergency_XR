# COMP5424 第五模块文案与素材交接包

本包为四楼教室至一楼训练终点的 VR 火灾疏散练习提供英文台词、标识纹理、基础模型、短提示音和可追溯来源。2026 年 10 月 1 日已完成内容制作、第三方素材许可核对、文件下载及文件层检查；Unity 导入、主场景整合与 Quest 3 验证仍需团队完成。文件存在和格式检查通过，不代表真机运行已通过。

## 六个外层文件夹

| 文件夹 | 存放什么 | 用来干什么 |
|---|---|---|
| [Assets](Assets/) | `Module5` 下的英文 cue JSON、逐条录音稿、原创模型/标识/WAV，以及 Kenney 模型/OGG 和许可 | 场景、UI 和声音负责人选择并导入所需内容。`Content` 提供文案数据，`Original` 保存本项目生成内容，`ThirdParty` 保存外部素材；JSON 不会自动实现交互，TXT 尚不是语音文件。 |
| [AlternativeFormats](AlternativeFormats/) | 桌子、椅子、门框、纸箱、单段楼梯的五个备用 FBX 及许可证 | 当团队选择 FBX 时替代对应 OBJ，不同时导入两套模型。 |
| [Docs](Docs/) | 六份参考项目、英文线索、素材登记、声音计划、交接验收与个人贡献文档 | 分配接收任务、核对素材使用方法、记录真实测试与个人贡献；无需导入 Unity。 |
| [Preview](Preview/index.html) | 离线网页、标识总览图和模型示意图 | 在浏览器查看英文内容、标识及模型示意，并试听提示音；示意图不是 Unity 或 Quest 运行截图，无需导入 Unity。 |
| [Research](Research/) | 五份 JSON，记录素材来源/许可/哈希、四个参考仓库的研究结果、研究文件链接、文件验证和原创规格 | 追查来源与研究依据，检查文件完整性；不属于 Unity 运行依赖，也不能代替真机验收。 |
| [Tools](Tools/) | `build_original_assets.py`，用于制作原创模型、SVG/PNG 标识和 WAV 提示音 | 需要修改或重新生成原创素材时运行；需 Python、Pillow 和可用字体。使用已有素材无需运行，该目录无需导入 Unity。`assemble_pack.py` 不包含在本包中。 |

团队仓库将本包保存于根目录 `COMP5424_Module5/`，保留六个文件夹的交接结构。它是素材包；Unity 工程位于仓库根目录。导入时将本包 `Assets/Module5` 复制到工程的 `Assets/Module5`，并提交 Unity 生成的 `.meta` 文件。模型可先沿用工程已有内容，备用格式按需使用。

## 先阅读与导入

1. 阅读 [英文台词与线索表](Docs/02_EnglishCueSheet.md)，与移动负责人确认三个按键占位符，再将内容交给 UI 负责人。
2. 阅读 [素材来源与使用表](Docs/03_AssetRegister.md)。先检查团队已有建筑 OBJ；已有桌椅、门或楼梯时优先沿用，避免重复导入。
3. 将本包 `Assets/Module5` 文件夹复制到团队 Unity 工程的 `Assets` 中。默认模型为 OBJ 与配套 MTL；备选 FBX 放在 `AlternativeFormats`，不同时导入两套格式。
4. 用 [声音与字幕计划](Docs/04_AudioPlan.md) 选择一套声音。默认合成提示音与 Kenney 备选音效不要同时播放。
5. 按 [交接与验收清单](Docs/05_HandoffAndAcceptance.md) 与场景、UI、设备和移动负责人联调，并填写 [个人贡献记录](Docs/06_ContributionLog.md)。

## 本包实际包含

- 七个旅程节点的英文文案、逐卡片录音稿和可读取的 `cues.en.json`；控制器按键仍用 `[待与移动负责人确认]` 标记。
- 从 Kenney 原站下载并保留 CC0 许可的五个家具模型：桌子、椅子、开放门框、纸箱、单段楼梯；纸箱与楼梯是可选备用。
- 两个原创简单 OBJ：电梯立面、用于标识贴图的面板。
- 八款原创英文标识，每款都有 PNG 与 SVG。左右箭头是可选方向，需按实际场景摆放；它们不是官方认证的消防标识。
- 四个原创低电平 WAV 提示音和三个 Kenney CC0 OGG 备选 UI 音效。旁白目前为英文录音稿，未生成语音录音。
- 四个参考仓库的事实与建议对照、来源和许可记录、文件统计与验证记录。
